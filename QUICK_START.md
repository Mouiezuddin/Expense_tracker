# ⚡ Quick Start Guide

## 🎯 For You (Project Owner)

### Upload to GitHub (3 commands)

```bash
# 1. Create repo at: https://github.com/new
#    Name: spendwise-expense-tracker
#    Don't initialize with anything

# 2. Connect (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/spendwise-expense-tracker.git

# 3. Push
git push -u origin main
```

Done! ✅

---

## 👥 For Users (Cloning Your Project)

### One-Command Setup

```bash
git clone https://github.com/YOUR_USERNAME/spendwise-expense-tracker.git && cd spendwise-expense-tracker/expense_tracker && python setup.py
```

Then:
```bash
# Windows
.venv\Scripts\activate

# Mac/Linux
source .venv/bin/activate

# Start
python manage.py runserver
```

Open: http://127.0.0.1:8000
